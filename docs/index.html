Sydney CBD Soil Landscapes

Publicly available soil landscape mapping for the Sydney CBD, showing what replaces a set of PDF figures: seven named map views, a categorised soil landscape layer over a clipped hillshade, and a full drawing title block.

  • 7 map views
  • Categorised polygons
  • Hillshade raster
  • Title block
  • 4.3 MB
Open the map Source on GitHub

Tip: everything a demo needs travels with the file. Save the page and it still works with no internet — only the OpenStreetMap basemap needs a connection, and the exported data draws without it.
